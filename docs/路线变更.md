## 怎么用

- 每次决定偏离基线，加一行即可，成本几十秒。
- 「原因」写当时真实的想法，不写事后总结出来的漂亮话——它是给三个月后的自己看的。
- 复盘和答辩时，这个文件就是「我知道自己在偏离计划，并且记录过」的证据。

## B3.5 的验收口径

只验证通路，不接业务：

1. 插件工程模板能 Run 起沙箱 IDE；
2. 一个 Action 能拿到「当前选中的文字」并显示出来；
3. 一个空 ToolWindow 能出现在右侧。

任何一步卡住即停——按 `AGENTS.md` 第 5 节，环境类问题立刻停下交人工，不反复试。
